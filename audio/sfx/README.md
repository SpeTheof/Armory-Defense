# 💥 SFX Folder (Explosions, Hits, UI, Enemy Sounds)

Drop your recorded sound effects here as .mp3 files!

The game auto-loads these files (replacing synthesized placeholders):

## Explosions
| File Name | Sound | Description |
|-----------|-------|-------------|
| `explosion_small.mp3` | Small explosion | Quick "PFUT!" |
| `explosion_medium.mp3` | Medium explosion | "BOOM!" |
| `explosion_large.mp3` | Large explosion (RPG) | "KABOOM!" |
| `explosion_massive.mp3` | Massive explosion (BFG) | "KABLAAM!" with rumble |

## Hit Sounds
| File Name | Sound | Description |
|-----------|-------|-------------|
| `hit_flesh.mp3` | Bullet hits flesh | Wet "THWACK!" |
| `hit_armor.mp3` | Bullet hits armor | Metallic "PING!" |

## UI Sounds
| File Name | Sound | Description |
|-----------|-------|-------------|
| `tower_place.mp3` | Tower placed | "KA-CHUNK!" |
| `tower_upgrade.mp3` | Tower upgraded | Rising "Da-DING!" |
| `tower_sell.mp3` | Tower sold | "Cha-CHING!" |
| `cant_afford.mp3` | Not enough gold | Sad "Buh-BUM" |
| `wave_start.mp3` | Wave begins | Military horn "BA-DA-DAH!" |
| `cash.mp3` | Money earned | Quick "CHING!" |

## Enemy & Game Sounds
| File Name | Sound | Description |
|-----------|-------|-------------|
| `enemy_death.mp3` | Enemy killed | Grunt "AUGH!" |
| `boss_appear.mp3` | Boss wave incoming | Ominous "BWOOOM..." |
| `game_over.mp3` | Mission failed | Sad "Wah-wah-wah-WAAH" |
| `victory.mp3` | All waves cleared | Triumphant "DA-DA-DA-DAAA!" |
